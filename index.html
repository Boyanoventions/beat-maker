Questions

How do I install it?

Download the ZIP for your computer, close Premiere, unzip it and run the installer (Install.bat on Windows, Install Beat Marker.command on Mac). Then open Window → Extensions → Beat Marker in Premiere.

Windows or macOS shows a security warning

That's normal for small independent tools. On Windows click More info → Run anyway. On Mac go to System Settings → Privacy & Security → Open Anyway.

What audio works best?

WAV gives the most reliable detection. MP3 support depends on Premiere. The clip should play at normal speed (100%), forward.
